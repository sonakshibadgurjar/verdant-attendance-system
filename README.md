# Verdant — Attendance Management System

A Flutter-based student attendance management application
with a forest-green UI and persistent attendance records.

## Features
- Student enrollment and management
- Attendance marking
- Attendance reports and filters
- CSV export
- Local data persistence
- Responsive Flutter interface

## Tech Stack
- Flutter
- Dart
- Shared Preferences
- Git and GitHub

## Getting Started
1. Install Flutter.
2. Clone this repository.
3. Run `flutter pub get`.
4. Run `flutter run -d chrome`.

## Backend Status
The current version focuses on the frontend and local
persistence. Face recognition backend integration is pending.
